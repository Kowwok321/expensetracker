
This is my Expense Tracker Python project. Here's what it aims to do:

Prints a menu with different feature choices
1. Add expense
	1a. Date
	1b. Expense Amount
	1c. Category
2. Add category
3. List expenses (sorted by date)
4. List categories
5. Exit

Everything is stored in a JSON file so you can close and resume when you need to add future expenses.
